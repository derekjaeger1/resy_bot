Manual Credentials (Advanced)

How to Get Credentials

  1. 1 Log into resy.com in your browser
  2. 2 Open Developer Tools (Cmd+Option+I on Mac, F12 on Windows)
  3. 3 Go to the Network tab
  4. 4 Navigate to any restaurant page
  5. 5 Find requests to api.resy.com
  6. 6
    Look for these headers:

    • Authorization

      Copy the value after ResyAPI api_key="

    • X-Resy-Auth-Token

      Copy the entire value

Credentials Expire

Resy periodically expires credentials. If snipes start failing, get fresh credentials.

Finding Venue IDs

To add a restaurant, you need its Venue ID from Resy:

  1. 1. Go to the restaurant's page on Resy
  2. 2. Open Developer Tools → Network tab
  3. 3. Look for a request to /find or /config
  4. 4. Find the venue_id parameter in the URL

Tip: Check NYC RSVPs for popular NYC restaurant release schedules.
